# Carpeta de Imágenes Institucionales

Coloca aquí las fotos reales de la Clínica San Martín para reemplazar las imágenes de stock.

## Nombres esperados por el sitio

| Archivo | Sección | Tamaño recomendado |
|---|---|---|
| `hero-bg.jpg` | Fondo del Hero | 1920×1080px |
| `clinica-equipo.jpg` | Sección Nosotros — imagen principal | 900×700px |
| `clinica-instalaciones.jpg` | Sección Nosotros — imagen secundaria | 600×400px |
| `clinica-laboratorio.jpg` | Card de servicios | 600×400px |
| `og-image.jpg` | Vista previa en redes sociales (OpenGraph) | 1200×630px |

## Formato recomendado
- Formato: **WebP** (mejor calidad/peso) o JPG
- Calidad: mínimo **85%**
- Sin marcas de agua
- Resolución: mínimo **72dpi** para web
